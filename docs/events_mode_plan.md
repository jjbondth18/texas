# Events Mode Plan

Events is a future activity hub for limited-time poker formats. The current version is a Coming Soon page only.

## Current Scope

- The Events page displays planned event cards.
- Event cards show Coming Soon messaging.
- Clicking an event card shows a Coming Soon toast.
- No event table is created.
- No chips or gems are charged.
- Quick, Browser, Friends Room, Training, and Replay flows are unchanged.

## Planned Events

### All-in Survival

- Fixed buy-in event table.
- Every N hands, the lowest stacks are eliminated.
- The last player standing wins.
- Future entry currency may be chips or gems.
- Future rewards may include chips, gems, or cosmetic frames.

### Lucky Spin Table

- Light entertainment table format.
- Random bonus pots can appear every few hands.
- Rewards rotate during the event window.
- Intended for casual, short-session play.

### Weekend Gem Cup

- Scheduled gem-entry event.
- Leaderboard-based progression.
- Reward pools can include gems and cosmetics.
- Opens only during configured event windows.

## Rules

- Do not use copyrighted film or show branding.
- Event names and visuals must be original.
- Events must not bypass wallet, buy-in, cash-out, or table fairness rules.
- Until fully implemented, Events remains Coming Soon and cannot enter gameplay.
