# Home Top Bar Actions

The Home top-right shortcut area only exposes three actions:

- `SOCIAL`
- `HELP`
- `EXIT`

Settings remains available from the left navigation only. The top-right Settings shortcut is intentionally removed to avoid duplicate entry points.

## Social

`SOCIAL` replaces the old Friends and Messages shortcuts. It is a lightweight placeholder for future friends and messages:

- No real friend system.
- No real message inbox.
- No Steam friends API.

## Help

`HELP` opens the Home `HELP & RULES` panel. The panel gives short local explanations for:

- Poker Basics
- Hand Rankings
- Game Modes
- Chips & Gems
- Table Rules

This panel is informational only. It does not change poker rules, economy, account balances, table behavior, or mode flow.

## Exit

`EXIT` keeps using the existing quit flow.
